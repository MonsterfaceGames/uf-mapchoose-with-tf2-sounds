Hello, This is my first counter strike 2 mapchoose plugin with team fortress 2 sounds. 

First of all. 
You need download Multiaddonmanager plugin from this link:https://github.com/Source2ZE/MultiAddonManager
and upload it into your server.
after that. You can get team fortress sounds from my steam workshop:https://steamcommunity.com/sharedfiles/filedetails/?id=3720959150
save it into you steam collect id.
after that click share button and copy only id Example: 3720959150
past 3720959150 into multiaddonmanager.cfg 
after past and save is now time for upload uf-mapchoose plugin.

inside uf-mapchoose plugin folder there is windows and for linux servers.
if you host linux server grap linux addons. for windows server grap windows addons.
upload addons folder inside you game/csgo folder.
go to addons/counterstrikesharp/configs/plugins/uf-mapchoose
from here edit maplist.cfg and config.cfg
maplist must be mapname and workshop map id Example mg_mapname:id
by configs.cfg you can edit but I recommented you edit only RTVdelay. 
keep the changemaproundend on false. or map wont be change ( Bug )

If you want you can check video tutorial from my youtube video: 
https://www.youtube.com/watch?v=mzaUDTXzrc0
